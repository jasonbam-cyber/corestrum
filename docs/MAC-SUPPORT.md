# Platform support and distribution status

The source quickstart is developed on macOS with Bun 1.4.1 and a modern browser. Linux GitHub CI checks the application and isolated container foundation. Native AppKit/WebKit packaging targets macOS 14 or later on the build host architecture; the source contains arm64 and x64 build selection, but this does not establish independent Intel/Mac acceptance. Windows is unqualified.

There is no published native installer. Developer ID signing, notarization, independent clean-Mac Gatekeeper acceptance, exact hardware/OS coverage and complete runtime redistribution materials remain required for binary releases. Do not bypass security prompts. Local ad-hoc builds are qualification artifacts only.

The community native workspace uses Application Support/Corestrum Community, with a separate Preview suffix for qualification. Source/browser startup uses ~/.corestrum-community. These do not automatically import one another or a licensed workspace. Use encrypted business recovery when intentionally moving data; reconnect your own providers.

No automatic updater or support-response SLA is provided. Preserve an encrypted backup and current reader before changing versions. Routines are local, start paused and stop when locked or quit. AI usage is customer-funded. The app does not confer SOC 2 attestation.
